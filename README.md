# Тема «Вега» для сайта teatrovega.es

Собственная тема WordPress для театральной студии «Вега» (Торревьеха).
Один стиль на всех страницах, афиша, группы, педагоги, спектакли, три языка (русский, испанский, английский).

Никаких конструкторов страниц и платных плагинов. Всё делается в обычной админке WordPress, код трогать не нужно.

- Подходит для WordPress 6.4 и новее, PHP 7.4 и новее.
- Тексты страниц редактируются стандартным редактором блоков.
- Языки работают через бесплатный плагин **Polylang**. Без него сайт работает на одном языке.
- Jetpack можно оставить: тема с ним не конфликтует.

## 1. Как скачать архив темы

**Способ 1 (проще).** На странице репозитория на GitHub откройте справа раздел **Releases** → «Тема Vega — последняя версия» и скачайте файл **`vega.zip`**. Архив пересобирается сам после каждого изменения темы в ветке `main`.

**Способ 2 (если в Releases пусто).** Нажмите зелёную кнопку **Code → Download ZIP**, распакуйте архив. Внутри будет папка `vega`: заархивируйте **только её** (правый клик → «Сжать» / «Отправить → Сжатая ZIP-папка»). Получится `vega.zip`.

> Важно: внутри архива должна сразу лежать папка `vega`, а в ней файл `style.css`. Архив всего репозитория WordPress не примет.

## 2. Перед установкой

1. **Сделайте резервную копию сайта**: в панели хостинга или плагином резервного копирования (например, Jetpack Backup или UpdraftPlus).
2. Если есть возможность, сначала попробуйте тему на тестовой копии сайта (многие хостинги делают её одной кнопкой: «staging»).

## 3. Установка Polylang и языков

Если хотите сразу три языка, сделайте это **до** создания стартового содержимого.

1. **Плагины → Добавить новый**, найдите **Polylang** (бесплатный, автор WP SYNTEX) → «Установить» → «Активировать».
2. **Языки → Языки**: добавьте по очереди **Русский**, **Español**, **English**. Русский сделайте языком по умолчанию (звёздочка в списке).
3. **Языки → Настройки → Адреса (URL)**: выберите «Язык задаётся по названию каталога в адресе» (адреса вида `/es/…`, `/en/…`) и включите скрытие кода языка по умолчанию в адресе — у русских страниц адрес останется без `/ru/`.
4. Если Polylang предложит назначить язык уже существующим страницам — назначьте **Русский**.

Отдельно включать переводы для событий, групп, людей и спектаклей не нужно: тема делает это сама.

## 4. Установка темы

1. **Внешний вид → Темы → Добавить → Загрузить тему** → выберите `vega.zip` → «Установить».
2. Нажмите **«Активировать»**.

После активации старые страницы, сделанные в Elementor, могут выглядеть непривычно: это нормально, ниже мы создадим новые.

## 5. Стартовое содержимое

1. В меню админки слева появится пункт **«Театр Вега»** — откройте его.
2. Вверху — блок **«Стартовое содержимое»**. Оставьте обе галочки и нажмите **«Создать стартовое содержимое»**.

Кнопка один раз создаёт:

- 13 страниц: Главная, Детская студия, Взрослым, Афиша и билеты, Педагоги, О театре, Actorre, Шхуна, «Под небом Испании», Hilos Rojos, Помочь театру, Контакты, Политика конфиденциальности;
- группы студии (Milky Way, Orion, Lyra, Hip-Hop, Contemporary) и программы для взрослых (БАС, Coral OLA) с расписанием и ценами;
- 5 педагогов (биографии — заглушки «текст уточняется»);
- события: фестиваль «Под небом Испании» (16–18 октября 2026) и концерт Екатерины Гопенко (25 октября 2026);
- 6 спектаклей репертуара (описания — заглушки);
- меню для шапки и подвала.

С Polylang всё создаётся на трёх языках и связывается как переводы. Без Polylang создаётся только русская версия.

**Существующие страницы не изменяются и не удаляются.** Если адрес уже занят старой страницей (например, `/kontakty/`), WordPress даст новой странице адрес с цифрой (`/kontakty-2/`). Старую страницу потом можно удалить в корзину и поправить адрес новой: «Страницы» → «Свойства» → «Ярлык».

Галочка «Сделать новую Главную главной страницей» меняет **Настройки → Чтение**. Если что-то пойдёт не так, там же можно вернуть прежнюю главную.

Повторно кнопка не запускается — так не появятся дубли.

## 6. Настройки темы «Театр Вега»

Пункт **«Театр Вега»** в меню админки. Здесь всё, что показывается на многих страницах сразу:

| Раздел | Что внутри |
|---|---|
| Логотипы | Teatro Vega, Actorre, «Шхуна». Пока логотип не загружен, на сайте пишется название текстом. Лучше всего — светлый PNG или SVG с прозрачным фоном. |
| Контакты | адрес (по нему строится карта), телефоны и WhatsApp для записи и руководителя, почта студии и ассоциации |
| Соцсети | Instagram, Facebook, YouTube театра; Instagram и Facebook «Шхуны» |
| Билеты и формы записи | общая ссылка на билеты и **пять отдельных ссылок на Google-формы** — у каждой своя кнопка на сайте |
| Пожертвования | получатель, IBAN, BIC, назначение платежа, Patreon, оплата картой |
| Служебные страницы | какая страница — «Афиша», «Помочь театру» и т. д. Заполняется само при создании стартового содержимого |

Правила:

- **Пустая ссылка — кнопка не показывается.** Так работают формы, Patreon, оплата картой, соцсети.
- Ссылки на формы прошедших лагерей и прошлогодних фестивалей сюда не вносите.
- **Пожертвования — только ассоциации Actorre.** Личные счета и личные платёжные ссылки сюда не вносите. Пока IBAN не заполнен, блок «Банковский перевод» на сайте не показывается (администратор видит подсказку).
- Реквизиты хранятся в базе сайта, а не в файлах темы, и в репозиторий не попадают.

## 7. Как поменять тексты на страницах

1. **Страницы** → наведите на нужную → **«Изменить»**.
2. Щёлкните по тексту и пишите. Сохраняйте синей кнопкой **«Обновить»**.
3. Подзаголовок под названием страницы — поле **«Отрывок»** в правой колонке (вкладка «Страница»).

Что есть в редакторе:

- **Секции.** Страницы собраны из блоков «Группа». У них есть стили (правая колонка → «Стили»): *Светлая секция* — тёплый светлый фон для длинных текстов, *Тёмная секция со звёздами*, *Оранжевая полоса*, *Карточка с рамкой*.
- **Блоки «Вега: …»** (кнопка «+» → раздел «Театр Вега»). Их содержимое собирается само, вручную ничего обновлять не нужно:
  - *Вега: афиша* — ближайшие события по дате; прошедшие пропадают сами;
  - *Вега: архив событий* — прошедшие события по годам;
  - *Вега: группы*, *Вега: расписание*, *Вега: цены* — собираются из карточек групп;
  - *Вега: люди* — педагоги, артисты или гости;
  - *Вега: спектакли* — репертуар;
  - *Вега: кнопка записи* — кнопка нужной Google-формы и рядом «Написать в WhatsApp»;
  - *Вега: кнопка «Билеты»*, *Вега: реквизиты для пожертвований*, *Вега: контакты* (с картой), *Вега: соцсети*, *Вега: логотип*.

  Настройки блока (какие группы, сколько событий и т. д.) — в правой колонке, когда блок выделен.
- **Стили абзацев и списков:** «Вводный абзац (крупнее)», «Рубрика (мелко, прописными)», «Список со звёздочками».

**Шаблоны страниц** (правая колонка → «Шаблон»):

- *По умолчанию* — название страницы крупно сверху, под ним текст.
- *Секции (без заголовка страницы)* — для главной и фестивалей: страница целиком из секций, первая секция служит заголовком.
- *Фестиваль «Под небом Испании» (своя палитра)* — те же блоки, но цвета фестиваля (ночная синь, золото, терракота) и шрифты Playfair Display и PT Sans. Подходит и для следующих лет: просто поменяйте год, даты, гостей и программу в тексте страницы.

## 8. Как добавить событие

1. **События → Добавить событие.**
2. Название. В основное поле — описание.
3. Справа **«Фото / афиша»** → «Выбрать фото» — афиша события.
4. Ниже, в блоке **«Данные события»**:
   - **Дата начала** — обязательно;
   - **Время начала** — можно оставить пустым;
   - **Дата окончания** — только для событий на несколько дней (фестиваль);
   - **Место**, **Цена** (как писать на сайте: «15 €, для членов Actorre 10 €»);
   - **Ссылка на билеты** — если пусто, кнопка «Билеты» ведёт на общую ссылку из настроек;
   - **Без кнопки «Билеты»** — для свободного входа;
   - **Раздел**: спектакль, концерт, фестиваль, мастер-класс, «Шхуна».
5. **Опубликовать.**

Событие само появится в афише и на главной, а после даты окончания — уйдёт в архив своего года. Встречи «Шхуны» (раздел «Шхуна») сами показываются на странице клуба.

## 9. Как добавить или изменить группу

**Группы → Добавить группу** (или откройте существующую).

- **Для кого**: детская студия или взрослым.
- **Идёт набор** — на карточке появится отметка.
- **Возраст от / до** — числа. Для взрослых «до» оставьте пустым — будет «от 17 лет».
- **Дни и время занятий** — одна строка на одно занятие. Из этих строк собираются расписание на сайте и строка на карточке.
- **Педагоги** — отметьте галочками; справа от имени можно написать, что человек ведёт в этой группе («вокал»).
- **Цены** — только числа: для членов Actorre и без членства. Если цена одна, заполните только «без членства». **Пояснение к цене** — например, «два занятия в неделю по полтора часа».
- **Кнопка записи** — на какую Google-форму ведёт кнопка на странице группы.
- Порядок групп на сайте — поле **«Порядок»** справа, в блоке «Атрибуты» (меньше число — выше).

Новый сезон: поменяйте расписание и цены в каждой группе — таблицы на страницах обновятся сами.

## 10. Как добавить педагога

**Люди → Добавить человека.**

- Имя — в заголовок, биография — в основное поле.
- **Фото** — справа, «Фото / афиша». Лучше вертикальное, лицо в верхней части кадра.
- **Роль**: педагог, артист или приглашённый гость.
- **Направления** — через запятую.
- **Действующий** — если человек больше не работает в театре, снимите галочку: он пропадёт со страницы «Педагоги», но его страница сохранится.
- Порядок — поле «Порядок» справа.

Страница «Педагоги» показывает только действующих педагогов. Артисты и гости пока нигде не выводятся. Когда начнёте наполнять каталог, добавьте на любую страницу блок *Вега: люди* и выберите «Артистов» или «Гостей». Общий список всех людей: адрес `/people/`.

## 11. Спектакли

**Спектакли → Добавить спектакль**: название, описание, афиша (справа), год премьеры, **галерея** (кнопка «Выбрать фотографии»; подписи к фото задаются в медиатеке) и **состав** (галочки + роль в спектакле). Репертуар показывается блоком *Вега: спектакли* (он есть на странице «О театре») и по адресу `/shows/`.

## 12. Переводы на испанский и английский

С Polylang у каждой страницы и записи есть три связанные версии.

- В списке страниц (событий, групп…) есть колонки с флажками языков. **«+»** — создать перевод, **карандаш** — открыть существующий.
- При создании перевода дата, время, цены, расписание и другие поля копируются сами — останется перевести тексты.
- В шапке сайта переключатель **RU · ES · EN** ведёт на эту же страницу на другом языке. Если перевода нет, ведёт на главную нужного языка.
- Все надписи темы (кнопки, подписи, месяцы, дни недели) уже переведены на три языка.

## 13. Меню

**Внешний вид → Меню.** Стартовое содержимое создаёт меню «Шапка (RU)», «Подвал (RU)» и такие же для ES и EN. С Polylang в разделе «Области меню» у каждого языка своё меню. Если какое-то меню не назначено, тема сама покажет меню из основных страниц на нужном языке.

Кнопка **«Записаться»** в шапке есть на всех страницах. Она ведёт на форму детской студии и пробного занятия. Если ссылка на эту форму пустая, кнопка ведёт на страницу «Детская студия».

## 14. Фотографии

- Фото — главный элемент сайта. Подойдут крупные живые снимки со сцены и с занятий.
- Тема обрезает фото **по верхней части кадра**, чтобы не отрезать головы. Если на фото много пустого неба над людьми, обрежьте его в медиатеке («Изменить изображение»).
- У каждой картинки заполняйте **«Альтернативный текст»** — коротко, что на фото («Дети из группы Orion на поклоне»). Это нужно незрячим посетителям и поисковикам.
- На главной вместо фотографии пока стоит рисунок созвездия Лиры. Чтобы поставить фото: «Страницы» → «Главная» → щёлкните по картинке → «Заменить».
- **Иконка сайта** (значок во вкладке браузера): «Внешний вид → Настроить → Свойства сайта». Пока она не загружена, показывается оранжевая звезда.

## 15. Отключение Bosa, Elementor и ElementsKit

Тема от них не зависит. Когда новые страницы готовы и проверены:

1. **Плагины** → «Деактивировать» ElementsKit, затем Elementor.
2. Пройдите по старым страницам: удалите ненужные в корзину (Страницы → «Удалить»). Корзина хранит их 30 дней.
3. Тему Bosa можно удалить в «Внешний вид → Темы» (откройте её → «Удалить»).

## 16. Для разработчика

```
vega/
  style.css, theme.json, functions.php, screenshot.png
  header.php, footer.php, index.php, page.php, front-page.php, single.php, 404.php
  single-vega_event|group|person|show.php, archive-vega_event|group|person|show.php
  page-templates/   sections.php, festival-sky.php
  template-parts/   page-header.php, sections.php, card-post.php
  inc/              helpers, i18n, setup, post-types, meta-boxes, queries,
                    components, blocks, settings, starter (+ starter/common|ru|es|en.php)
  assets/css/       theme.css (все стили; переменные в начале), fonts.css, admin.css, editor.css
  assets/js/        site.js (меню, «Скопировать», карта), blocks.js (блоки редактора), admin.js
  assets/fonts/     Jost, Sofia Sans Condensed, Golos Text, Playfair Display, PT Sans (OFL, кириллица + латиница)
  languages/        vega.pot, ru_RU.po/.mo, es_ES.po/.mo
tools/
  i18n.py           сбор строк (.pot) и компиляция .po → .mo на чистом Python
  build-zip.sh      сборка vega.zip
```

- Цвета, шрифты, отступы — в `theme.json` (палитра, шрифты, размеры) и в начале `assets/css/theme.css` (CSS-переменные). Компоненты берут цвета из переменных `--s-*` и сами подстраиваются под светлую секцию. Палитра фестиваля — класс `palette-sky`.
- Надписи темы пишутся по-английски через `__( '…', 'vega' )`. После изменения: `python3 tools/i18n.py pot`, перенести новые строки в `ru_RU.po` и `es_ES.po`, затем `python3 tools/i18n.py mo` и `python3 tools/i18n.py check`.
- Названия полей в админке — по-русски прямо в коде (`inc/meta-boxes.php`, `inc/settings.php`), чтобы не зависеть от языка админки.
- GitHub Actions (`.github/workflows/theme.yml`) проверяет синтаксис PHP на 7.4 и 8.3, собирает `vega.zip` и публикует его в Releases при изменениях в `main`.
- Сборки через npm нет: стили и скрипты пишутся как есть.
